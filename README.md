# Delivery Task Agent using A* Pathfinding

## Overview
This project simulates a delivery agent that picks up a parcel from a restaurant and delivers it to a customer using the A* Pathfinding Algorithm.

## Features
- A* Search Algorithm
- Obstacle Avoidance
- Restaurant Pickup
- Customer Delivery
- Animated Visualization using Matplotlib

## Technologies Used
- Python
- NumPy
- Matplotlib
- Heapq
- IPython

## How It Works
1. Agent starts at a predefined location.
2. Finds the shortest path to the restaurant.
3. Picks up the parcel.
4. Finds the shortest path to the customer.
5. Completes the delivery.
